## 1. Purdue IEEE ROV (Remotely Operated Vehicle)
*Software Lead | ROS2, C++, Python, UART, Raspberry Pi, STM32*

As the Software Lead for the **Purdue IEEE ROV Team**, I guide the development of our underwater vehicle's software ecosystem. The software stack is split into the surface control station (onshore laptop) and the internal electronics core (onboard Raspberry Pi 4 communicating with electrical boards).

### Architectural Core
* **Control Stack (Surface/Frontend):** [X18-Surface](https://github.com/purduerov/X18-Surface) handles telemetry rendering, camera feeds, and pilot input translation. It interfaces with the operator's joystick and streams control payloads over ethernet.
* **Onboard Systems (Core/Backend):** [X18-Core](https://github.com/purduerov/X18-Core) is built on **ROS2 (Robot Operating System)**. Nodes coordinate task execution, read sensor data, ingest camera feeds, and output thruster vectors.
* **Device Communication:** We design custom UART packets to interface the Raspberry Pi 4 with STM32 microcontrollers. These packets are validated using CRC-32 checksums to prevent corrupted packets from misfiring motors or tools in underwater conditions.

* **GitHub Organization:** [Purdue IEEE ROV](https://github.com/purduerov)
* **Frontend Control Dashboard:** [purduerov/X18-Surface](https://github.com/purduerov/X18-Surface)
* **Backend Robotics Core:** [purduerov/X18-Core](https://github.com/purduerov/X18-Core)

## 2. Investopedia Clone
*Full-Stack Engineer | Java, Spring Boot, AWS RDS, LSTM Deep Learning, Tailwind CSS*

This project is a real-time stock simulator and educational platform designed to replicate the trading experience of Investopedia. Users can manage a virtual portfolio, fetch real-time market data, and leverage an AI model to predict price trends.

### Backend & Forecasting Engine
* **Service Layer:** The backend is built using **Java** and **Spring Boot**, exposing robust REST APIs for transaction records, portfolio tracking, and user profile management. Data is persisted in **AWS RDS**.
* **Price Prediction:** I trained a **Long Short-Term Memory (LSTM)** deep learning model to forecast stock prices (specifically AAPL and MSFT) with 75-80% accuracy based on historical market trends.
* **Frontend Interface:** Built with a clean, responsive layout utilizing **Tailwind CSS** and hosted on **GitHub Pages**.

## 3. Spotify Del Norte
*Full-Stack Developer | Node.js, Express, React, JSON Web Tokens (JWT), CSS/Tailwind*

Spotify Del Norte is a full-featured music streaming web application clone. It allows users to play songs, create playlists, and log in securely to their accounts. 

### The JWT Authentication Challenge
One of the most complex challenges we faced was the implementation of secure **JSON Web Tokens (JWT)** for user sessions. We had to architect a flow where:
1. The backend issues a token upon successful verification.
2. The token is stored in an `HttpOnly`, secure cookie.
3. The client browser automatically includes the cookie in cross-origin HTTP requests, avoiding exposure to Cross-Site Scripting (XSS) attacks.

## 4. Bublur
*Backend & Infrastructure | Python, Flask, PostgreSQL, Google Cloud Platform (GCP), Tailwind CSS*

Bublur is a full-stack social media application where communities converge around randomly assigned daily topics. Users post responses and engage in real-time discussions.

### System Infrastructure
* **Backend:** Engineered with **Python** and **Flask**, hosting a RESTful API designed to manage topic generation, text submission, and user votes.
* **Database & Cloud:** Utilizes a **PostgreSQL** database managed in **Google Cloud Platform (GCP)**, ensuring robust reliability, indexed query performance, and horizontal scaling.
* **Styling:** The frontend features a fast-loading, clean layout using **Tailwind CSS**.
